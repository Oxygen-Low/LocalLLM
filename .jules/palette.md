- Discovered that 204 <button> tags across the application were missing the explicit `type="button"` attribute.
- Used a regular expression in a Node.js script (`fix_buttons.js`) to safely inject the `type="button"` attribute into multi-line button declarations without affecting existing bindings (`[type]` or `type=`).
- Explicitly defining the button type prevents accidental form submissions across the application, addressing a widespread micro-UX/accessibility issue.
